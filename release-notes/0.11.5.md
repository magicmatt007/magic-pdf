## What's new in 0.11.5

**Settings**
- With several magic-pdf windows open, the windows no longer undo each other's
  settings: a signature drawn or a setting changed in one window stays when another
  window saves later.
- An unreadable settings file is kept as a backup instead of being replaced.

**Updates**
- Updates now also install over slow connections. Before, a download that took longer
  than two minutes was cancelled.

**Windows**
- Files on network shares show their usual \\server\share path, and **Open containing
  folder** opens them in Explorer.
- Moving a tab to another window now includes a comment you were still typing.
