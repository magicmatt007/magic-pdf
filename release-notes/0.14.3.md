## What's new in 0.14.3

**Start screen**
- The start screen shows the magic-pdf logo, and "Open a PDF…" is now a clear main
  button.
- The list of recent files stays within its column: long names end in "…", and only
  the last two folders are shown (the full path appears when you point at a file).
- The tools in the toolbar are greyed out until a document is open.

**Recent files**
- magic-pdf now remembers your last 100 files instead of 15. The start screen and
  File → Open recent still list the 15 most recent ones (with your pinned files on top),
  and a search field finds any file in the history by part of its name or folder.
