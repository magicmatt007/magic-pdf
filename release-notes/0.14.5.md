## What's new in 0.14.5

**Many open files**
- The row of open files can be scrolled with the mouse wheel, and the file you switch
  to always scrolls into view.
- Long file names are shortened in the tabs, so more of them fit (the full path shows
  when you point at a tab).
- When not all tabs fit, a button at the end of the row lists all open files.
