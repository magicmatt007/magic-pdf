## What's new in 0.4.0

**Annotations**
- **Lines, arrows, polygons and clouds.** Drag a line or arrow (Shift: 45° steps). For polygons and clouds, click the corners and finish with Enter or a double-click, or drag a rectangle. All shapes share one toolbar button with a ▾ menu.
- **Stamps:** APPROVED, REVIEWED, DRAFT, CONFIDENTIAL and more, your own texts, or a picture. An optional second line shows your name and the date.
- **Signatures:** draw one with the mouse or use a scanned picture, then click to place it.
- **Copy and paste annotations** with Ctrl+C / Ctrl+V, also between tabs.
- **Comments sidebar:** search, filter by type, author or status, reply to comments and set a review status (Accepted, Rejected, …).

**Scanned PDFs**
- **Pages → Recognise text (OCR)** makes scanned pages searchable and selectable. It needs [Tesseract](https://tesseract-ocr.github.io/tessdoc/Installation.html), and the dialog explains how to install it.

**Everyday use**
- **Edit → Settings (Ctrl+,)** gathers all preferences in one place.
- magic-pdf reopens the files from last time when started without a file.
- Recent files can be pinned to the top of the list.
- Thumbnails mark every page that is on screen.

**Linux**
- New **AppImage** download that updates itself like the Windows and macOS versions.
