## What's new in 0.15.0

**Edit text**
- A new Edit text tool (the T button next to Select text): click a line of text on the
  page, change it and press Enter. Esc cancels, and Undo brings the old text back.
- The text keeps its font when that font has the characters you type; otherwise a
  similar standard font is used, at the same place, size and colour.
- Characters that cannot be written (for example Chinese in a Latin font) are refused
  with a message, and the text stays as it was.

**Signatures**
- magic-pdf now checks whether the signer's certificate is trusted, and shows it in the
  signature bar and details: trusted, not trusted (and why), expired or revoked.
- A signature's timestamp is shown with the time and the authority that issued it.
- Undoing a page change in a signed PDF no longer breaks its signatures.

**German**
- Error messages from page changes are now in German too.
