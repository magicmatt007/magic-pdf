## What's new in 0.14.1

**Large documents**
- magic-pdf uses much less memory with long documents: about half as much after
  paging through 800 pages.
- Searching a long document no longer makes the window stutter, even with tens of
  thousands of matches. Each result in the list shows two lines of text with the match
  always visible.

**German**
- Error messages, for example when saving, printing or signing fails, are now in German
  too.
