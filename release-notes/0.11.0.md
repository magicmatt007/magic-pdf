## What's new in 0.11.0

**Replies**
- Replies now show on the page too: click an annotation to see its replies in the
  popup, and answer right there. Hovering over an annotation shows them as well.
- Replies you write in magic-pdf now also appear in PDF-XChange, Acrobat and other
  PDF applications once you save the file.

**Files**
- **Open containing folder** (File menu, or right-click a tab) shows the file in
  Explorer, Finder or your Linux file manager.
