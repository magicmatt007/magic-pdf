## What's new in 0.12.1

**German**
- Many texts that were still in English in the German interface are now translated,
  among them the titles of the Crop, Header and footer and Optimized copy windows,
  some entries of the page menu, printing messages, the list of OCR languages and the
  keys in the list of keyboard shortcuts.

**Starting**
- New installations start with the start screen instead of reopening the files from
  last time. If you used magic-pdf before, it keeps reopening them; untick Settings →
  Starting → "Reopen the files from last time" to get the start screen.
