## What's new in 0.2.0

**Annotations**
- **Text boxes with rich text:** type directly on the page; bold, italic, underline, strikethrough, colours and sizes per word, left/centre/right alignment (formatting bar and Ctrl+B/I/U). Saved as standard PDF rich text, so Acrobat and PDF-XChange show the formatting.
- **Move and resize** annotations by dragging; handles on selected shapes, drawings and text boxes (Shift keeps proportions); arrow keys nudge (Shift: 10 pt).
- **Colour picker** everywhere: 70 colours, recent colours, custom colour or hex code; separate fill colours and "No fill"; a tool options bar under the toolbar.
- Colours of annotations from saved files are shown correctly; turning fill off works.
- **Esc** cancels what is in progress and returns to the Hand tool.

**Windows and tabs**
- PDFs opened from Explorer join the running magic-pdf window as a tab.
- Drag a tab out of the window to give it its own window, or onto another magic-pdf window to move it there (unsaved changes included). Right-click a tab for "Move to new window / Move to window".

**Updates**
- magic-pdf checks for new versions at most once a day (Help menu to turn it off). On Windows, **Install** downloads the new installer, verifies its checksum and updates in place.
- New app icon.

0.1.0 has no update check, so install 0.2.0 by hand once; later versions arrive by themselves.
