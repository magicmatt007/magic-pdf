## What's new in 0.14.0

**Combine files**
- File → Combine files puts several PDFs, in the order you choose, into one new PDF.
  Add files with the button or by dropping them on the window.
- Each file gets a bookmark in the new PDF, with that file's own bookmarks under it.

**Signed documents**
- Changing bookmarks or document properties of a signed PDF no longer breaks its
  signatures, just like adding comments or changing pages.
- Before redacting a signed PDF, magic-pdf now tells you that its signatures will no
  longer be valid.

**Dates**
- Dates are now shown and stored in your local time instead of UTC: in signatures,
  comments, replies and stamps.

**German**
- The messages after saving pictures, extracting pages, splitting a document and saving
  an optimized copy are now in German too.
