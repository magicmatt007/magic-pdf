## What's new in 0.11.3

**Forms**
- Text you are still typing into a form field is now saved when you press Ctrl+S. It was
  lost if the cursor was still in the field.
- Undoing a page change (such as a rotation) no longer loses text typed into a form field
  just before.

**Bookmarks**
- Editing a bookmark no longer changes the others: they keep jumping to the exact spot on
  the page, links to web pages keep working, and colours, bold or italic text and
  collapsed bookmarks stay as they were.

**Comments and replies**
- Replies containing characters such as €, dashes or curly quotes now appear correctly in
  other PDF applications.
- Deleting a comment also deletes the replies other applications wrote to it, instead of
  leaving them behind in the file.
- Replies to replies (as Acrobat writes a conversation) now show in the comment's thread.
- Optimized copies no longer show replies as note icons on the page.

**Saving**
- A file is completely written to disk before it replaces the old one, so a crash or
  power cut right after saving cannot leave an empty file.
- Saving through a shortcut (symbolic link) on Linux and macOS updates the original file.
